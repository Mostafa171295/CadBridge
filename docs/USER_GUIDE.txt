CAD Bridge  -  pick a script, set the values, press Run: it runs inside SolidWorks / AutoCAD / Civil 3D / Revit
================================================================================================================

Start
  Open CadBridge.sln in Visual Studio, press Ctrl+Shift+B, then F5.
  (The first build needs internet to download the Roslyn and AvalonEdit packages.)
  If SolidWorks is not under C:\Program Files\SOLIDWORKS Corp, change SolidWorksApiDir in CadBridge.csproj. SolidWorks is optional: without its DLLs the program still builds (the SolidWorks tab just cannot connect).

Projects
  Top bar: choose a project or press "New project". Everything the scripts save goes to
  Documents\CadBridge\Projects\<project>\Files   (button "Open files folder").
  Scripts you save belong to the project: Projects\<project>\Scripts\<tab>.

Script library (left side of every tab)
  Built-in examples + your project scripts. Double-click to load. "Save script..." keeps your version in the project.
  Built-in examples live in Documents\CadBridge\Scripts\<tab>. Delete a file there and it comes back on the next start.

Parameters
  In a script, write  {{Name=default}}  where a number or text should be changeable, for example
      double Span = {{Span=12000}};        string PartName = "{{PartName=Girder}}";
  The program shows one input box per name above the editor. Strings with backslashes: use @"..." .

Tabs
  SolidWorks : open SolidWorks -> Connect -> run scripts (Box, Piston, Girder_I_Section...).
               Assemblies: "Build assembly" button (side by side) or scripts Assembly_At_Origin / Assembly_Mate_Planes.
               Batch_Export converts every part in a folder to STEP / IGES / STL...
  AutoCAD    : open AutoCAD -> Version = Auto (or your year) -> Connect -> run scripts.
               Points_From_Table draws points from .csv/.xlsx, Batch_DWG_to_PDF plots every DWG in a folder.
  Civil 3D   : like AutoCAD, plus the object "civil" for Civil 3D (surfaces, alignments...).
  Revit      : FIRST TIME ONLY - close Revit, pick the Version, press "Install add-in". Then open Revit + a project
               -> Connect -> run scripts. (TableReader is not available in Revit scripts.)

Editor: colors, line numbers and auto-complete (starts when you type a letter). F5 = Run.

Making an .exe
  Build in Release mode and copy the WHOLE folder CadBridge\bin\Release\net48\ (the .exe needs the DLLs and the
  Scripts folder next to it).

Security: the program runs whatever you load with full rights. Only run code you trust.

Drop-down lists (read from Revit)
  In a Revit script write  {{Level=@levels}}  and the box becomes a list filled FROM the open Revit project.
  Ready lists: @levels  @materials  @materialClasses  @columnTypes  @beamTypes  @footingTypes  @wallTypes  @floorTypes
  The lists are read when you press Connect (press Connect again to refresh after you change the Revit project).
  You can also write your own fixed list:  {{Scope=Type|Instance}}.  Boxes from Revit can still be typed by hand.
  Lists of family files on this PC:  @columnFiles  @beamFiles  @footingFiles  (read from Revit's library folders
  "Structural Columns" / "Structural Framing" / "Structural Foundations", and from Documents\CadBridge\Families\<same folder name>).
  A script can load the picked file into the project before drawing (see Columns_Grid).
  Example script: Columns_Grid (columns with the type, material, level and Type/Instance size chosen from lists).


Build a structure from A to Z  (Revit tab)            (v4)
  Scripts in Scripts\Revit are numbered. Run them in this order (double-click in the Script library, set the values, Run):
    00_Build_Order   prints this list (changes nothing)
    01_Grids         axes: vertical 1,2,3... and horizontal A,B,C...   (SpansX = 4x5000, SpansY = 3x5000 ...)
    02_Levels        Foundation, Ground, Level 1..n, Roof  (+ structural plan views)        (Heights = 4x3200)
    03_Footings      isolated footings under the grid intersections                          [family folder]
    04_TieBeams      tie beams between the footings (on the foundation level)                [family folder]
    05_Columns       columns on every intersection, storey by storey (BaseLevel -> TopLevel) [family folder]
    06_Beams         floor beams between the columns, one level or a range of levels         [family folder]
    07_Slabs         floor slabs: one slab over everything, or one per bay; thickness in mm
    08_Walls         walls / shear walls on the perimeter or on all grid lines, storey by storey
    09_Roof          roof on the top level: Flat / Hip / Gable / Shed, overhang, slope in %
  Every script reads what the previous ones made (grids, levels, columns...) from the open Revit project, so you can
  stop and continue any time, and run a script again for another level range. Running a script twice does not duplicate:
  an element at the same place and level is skipped.
  Grids must be parallel to the X / Y axes (the 01_Grids script draws them that way).

Family folder button  (footings, columns, beams)
  Next to every  FamilyFile  box there is a "Folder..." button. Pick the folder that holds your own .rfa files
  (sub folders are included). Only that folder is listed then; press "Default" to go back to Revit's library folders.
  The choice is remembered for each object (footings / columns / beams are separate) in
  %APPDATA%\CadBridge\family-folders.txt, so you pick it once. The family is loaded into the project when the script runs.
  Walls, slabs and roofs are Revit "system families": they have no .rfa file, you choose their TYPE from the project list.
  The Revit tab can read the family lists even before you press Connect (it only reads the disk).

Notes for script writers
  Scripts can use  #if REVIT2022_OR_NEWER ... #else ... #endif  (symbols REVIT2021 ... REVIT2026 and REVIT2021_OR_NEWER ...
  REVIT2026_OR_NEWER are defined for the Revit year you picked). The new list @roofTypes is available in boxes.


NEW IN v5  -  more building scripts + professional quantity take-off (Revit tab)
--------------------------------------------------------------------------------
  10_Doors_Windows   doors / windows at the middle of the bays. Run once with Kind = Window and once with Kind = Door.
                     Lines = Perimeter | All | grid names (A, C, 1);  Bays = All | 1, 3;  Width / Height / Sill in mm.
                     New lists in boxes:  @doorTypes  @windowTypes
  11_Rooms           creates the rooms in every closed area and writes Floor / Wall / Ceiling / Base finish text and the room height.

  20_Takeoff_Structure      -> Excel  BOQ_Structure_<date>.xlsx      (the model is NOT changed)
      footings, raft, tie beams, columns, beams, slabs, RC walls: concrete m3, formwork m2 (from the 3D faces), steel (kg/m3 ratios),
      plain concrete, excavation (per footing or bulk) and backfilling.
      Sheets: BOQ (Arabic + English, rate and amount columns, live formulas) | ByLevel | Detail (one line per element) | Notes.
  21_Takeoff_Architecture   -> Excel  BOQ_Architecture_<date>.xlsx
      masonry by type, internal / external plaster, floors / skirting / wall finish / ceilings from the ROOMS,
      doors and windows by type and size, sills, thresholds, RC lintels, roofs and finish floors.
      Sheets: BOQ | Walls | Rooms | Openings | Notes.
  How to use the Excel file: type your unit rates in the yellow cells; amounts and totals are calculated by Excel.
  Every figure can be checked in the Detail / Walls / Rooms sheets (they can be filtered). The Notes sheet lists the method,
  the assumptions and the warnings (elements without volume, rooms without finishes ...).

  Shared library: Lib\CbLib.cs.txt is compiled into every script that uses Cb. / CbGrid / CbXlsx / CbBoq (no copy needed).
  Scripts can write their own Excel files:  CbXlsx.Table(...), CbBoq, CbXlsx.Save(path, sheets).
  The program now also needs System.IO.Compression (already part of .NET Framework 4.8 / .NET 8).
  NOTE: your Documents\CadBridge\Scripts\Revit folder keeps the old copy of 00_Build_Order - delete that file so the new one is copied.
  The security note above (scripts run with full rights) applies to the new scripts too.


ALSO IN v5  -  stairs, slab openings, railings, fence walls (Revit tab)
-----------------------------------------------------------------------
  12_Stairs          real Revit stairs between levels. Shape = Straight | UTurn | LTurn, Direction, Turn, Width, Riser, Tread.
                     AtGrid = B-2 (a grid crossing) or absolute OffsetX / OffsetY. One stair per storey from FromLevel to ToLevel.
                     Opening = Yes cuts a rectangular shaft in the slab above (only where the head room is under Headroom).
                     New list in boxes: @stairTypes.   Multi-run stairs (UTurn / LTurn) - try on a COPY first and check them in 3D.
  13_Slab_Openings   shaft openings that cut all slabs between LowerLevel and UpperLevel: Rectangle or Circle,
                     placed with AtBay = A-B/1-2 (centre of a bay) or AtGrid = B-2, plus OffsetX / OffsetY.
  14_Railings        railings: Source = SlabEdge (outer edge of the slab) | SlabOpenings (around every hole) | GridRectangle (Offset).
                     New list in boxes: @railingTypes.
  15_Fence_Walls     site boundary wall or roof parapet: four walls around the grid area, Offset from the outer grids,
                     OmitSides = N, S, E, W to leave a gate open.
  21_Takeoff_Architecture now also lists stairs (number, risers) and railings (length in metres).
  Notes: stairs and railings use Revit API members that changed between Revit years; the scripts read the result back and write
  warnings in the log. If a run fails nothing is left half-made (the stair is cancelled).

v7 - New look + Night mode
  Blue-on-white style with a soft glow. The sun/moon switch in the header toggles Night mode
  (remembered in %AppData%\CadBridge\theme.txt). All colours live in Skins\Light.xaml and Skins\Dark.xaml.

v8 - Browse button + hide/show Code and Guide
  Takeoff scripts 20 / 21 / 22 have a new SaveFolder parameter with a Browse... button (empty = project Files folder).
  Browse... also appears next to any parameter ending with Folder or File.
  The Guide and Code buttons (next to Run) hide / show the how-to text and the code editor; remembered, all tabs.
